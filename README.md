## 🧠 Overview

A **production-quality E-Commerce store frontend** crafted with React and Vite. The project prioritizes visual polish, component architecture, and performance — with a Figma-designed UI implemented in Tailwind CSS using Radix UI and Shadcn component primitives.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Premium UI/UX** | Clean, professional design with focus on usability |
| 📱 **Responsive Design** | Fully optimized for mobile, tablet, and desktop |
| ⚡ **Performance** | Blazing-fast load times powered by Vite |
| 🎦 **Smooth Animations** | Framer Motion transitions and hover effects |
| 🧱 **Premium Components** | Radix UI + Shadcn UI component library |
| 🛍️ **Product Catalog** | Browse, filter, and view products with detail pages |
| 💳 **Cart System** | Add to cart, update quantities, and checkout flow |

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| **Framework** | React + Vite |
| **Styling** | Tailwind CSS |
| **Components** | Radix UI + Shadcn UI |
| **Icons** | Lucide React + MUI Icons |
| **Animations** | Framer Motion |
| **Routing** | React Router |
| **Design** | Figma |
| **Deployment** | Vercel |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/JSR2406/E-commerce-store-.git
cd E-commerce-store-

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
